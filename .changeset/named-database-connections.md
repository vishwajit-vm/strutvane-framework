Several databases at once (CONSISTENCY #132, RFC-0007). `DB_*` stays the default connection; extra connections are declared by name in `config/database.ts` (`connections: { pgsql: { driver: 'pgsql' }, reports: { driver: 'sqlite' } }`) and read their own `DB_<NAME>_*` keys. Use them with `db.connection('<name>')` (new in `@strutvane/framework/database`), a model's `connection: '<name>'` option, `Model.on('<name>')` for one query or save, and `--database=<name>` on `migrate`, `migrate:status`, `migrate:rollback`, `migrate:reset`, `migrate:refresh`, `migrate:fresh` and `db:seed`. Transactions are per connection. Every connection is checked and opened on first use, never at boot: an app whose `.env` lists every key empty still starts, and the first use fails with `database_not_configured` naming the key to set (also `unknown_connection`, `invalid_connection_name`, `invalid_database_config`, `secret_in_config`). New exports: `DatabaseManager`, `DatabaseManagerToken`, `connectionEnvPrefix` (root); `db`, `connectionNamed`, `runWithConnections`, `forgetConnection`, `isConnectionName`, `DEFAULT_CONNECTION`, `databaseEngineOf`, `DatabaseKeys` (`/database`); `useConnection(connection, name)` and `databaseSettings(env, root, keys)` take an optional name / key prefix.
